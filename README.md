# Bajaj Carrera Motos Medellín 🏍️🇨🇴

Este proyecto es el sitio web interactivo y moderno para el concesionario oficial **Bajaj Carrera Motos** ubicado en Laureles - Estadio, Medellín.

## 🚀 Características y Secciones Incluidas

1. **Top Bar y Navegación**:
   - Selector interactivo de países y menú principal.
   - Accesos directos a Financiación, Promociones y Postventa.
   - Enlaces directos de contacto y ubicación física.
2. **Video de Introducción (Splash Screen)**:
   - Video inmersivo a pantalla completa con branding de Bajaj, botones para ingresar al sitio web y activar sonido.
3. **Catálogo de Motos Dinámico**:
   - Pestañas interactivas: *Todas*, *Boxer*, *Pulsar*, *Discover*, *Dominar*, *Motocarros*.
   - Modelos actualizados y personalizados (Boxer CT100 KS Racing, Pulsar N160 Pro, Pulsar NS400Z, Dominar 400 Touring, etc.).
   - Precios sugeridos, especificaciones y botón de cotización.
4. **Hero Slider Principal**:
   - Carrusel de campañas destacadas y promociones (Aceites Genuinos, Nueva Línea Boxer).
5. **Cotizador Integrado con WhatsApp**:
   - Formulario de contacto que captura nombre, ciudad y modelo de interés.
   - Envío automático del lead formateado directamente al WhatsApp oficial del concesionario.
6. **Módulo de Financiación y Repuestos**:
   - Información de créditos con aprobación en minutos.
   - Garantía extendida y repuestos 100% originales.

---

## 🛠️ Tecnologías

- **HTML5 & CSS3**
- **Tailwind CSS** (Diseño totalmente responsive móvil/escritorio)
- **Vanilla JavaScript** (Interactividad, sliders, y generador de enlaces de WhatsApp)
- **FontAwesome & Swiper.js**

## 🌐 Cómo visualizar la página

Para ver la página funcional en tu computadora:
1. Clona o descarga este repositorio.
2. Abre la carpeta del proyecto.
3. Haz doble clic en el archivo index.html para abrirlo en tu navegador favorito.
